# Trade

Boş beyaz sayfa gösteren minimal Next.js App Router projesi.

## Yerel geliştirme

```sh
npm ci
npm run dev
```

Tarayıcıda http://localhost:3000 adresini açın.

## Üretim kontrolü

```sh
npm run build
npm start
```

## Vercel

Projeyi Git deponuza gönderin ve Vercel'de yeni proje olarak içe aktarın.
Framework olarak Next.js, kök dizin olarak bu klasörü seçin.
Varsayılan kurulum ve build ayarları yeterlidir. Ortam değişkeni gerekmez.

Ana sayfa: `app/page.js`.
